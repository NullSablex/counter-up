# Contributing

Contribuições são muito bem-vindas.

Se você encontrou um bug, quer sugerir melhoria ou enviar código, obrigado por contribuir com o projeto.

## Boas-vindas

Bem-vindo(a) ao projeto `counter-up`.
Toda contribuição é valorizada, seja correção de bug, melhoria de documentação, sugestão de API ou nova funcionalidade.
Se for sua primeira contribuição em open source, este repositório também foi pensado para te receber bem.

## Como contribuir

1. Faça um fork do repositório.
2. Crie uma branch para sua alteração.
3. Faça mudanças pequenas e focadas.
4. Atualize documentação quando houver mudança de comportamento ou API.
5. Atualize o `CHANGELOG.md` para mudanças visíveis ao usuário.
6. Abra um Pull Request com descrição clara do problema e da solução.

## Build local

`npm run build` é recomendado ao alterar arquivos em `src/` para regenerar os artefatos em `dist/`.

## Pull Requests

1. Prefira PRs curtos e objetivos.
2. Inclua contexto, motivação e impacto da mudança.
3. Adicione ou atualize exemplos quando fizer sentido.
